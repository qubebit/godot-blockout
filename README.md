# Godot CSG Tools

[![Github tag](https://badgen.net/github/tag/qubebit/godot-csg-tools)](https://github.com/qubebit/godot-csg-tools/tags)
[![GitHub](https://img.shields.io/github/license/qubebit/godot-csg-tools)](https://github.com/qubebit/godot-csg-tools/blob/master/LICENSE)

This repository contains a Godot plugin for CSG (Constructive Solid Geometry) tools, which provides a set of utilities and features to enhance the workflow of creating and manipulating CSG objects in the Godot Engine.

> [!WARNING]
> This repository is in early development and is not yet ready for production use. The API is subject to change without deprecation, and there may be breaking changes in future releases.
